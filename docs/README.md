## 一、项目说明

### 1.1 解决什么

在 DRG 付费下，把「官方结算返回」与「院内 HIS 数据」对起来，回答四个问题：

1. **分组对不对** —— 自建引擎按 CHS-DRG 2.0 规则分组，与官方结算结果逐例比对（ADRG / 四位码一致率）；
2. **钱差在哪** —— 结算清单与 HIS 费用明细逐例勾稽，给出盈亏与差异分类；
3. **在院的病例现在什么状态** —— 在院模拟器实时给出预测分组、费用与中治率；
4. **编码有没有漏** —— 编码助手基于用药/手术提示可能遗漏的诊断，只给提示不写码。

### 1.2 组成部分

| 目录 | 作用 |
|---|---|
| `src/etl/` | 数据作业与运行时模块（`s*.py` 作业、`dbio`/`ddlio` 取数、`drg_engine` 分组引擎、`tcm_ratio` 中治率） |
| `src/web/backend/` | FastAPI 后端：登录/鉴权/权限矩阵/审计/运维接口 |
| `src/web/frontend/` | Vue3 前端（仓库内为源码，部署包内为已构建的 `dist/`） |
| `src/config/` | 连接与凭据（`settings.py` / `secure.py`）、源库契约两份 JSON、字典产物与规则黑白名单 |
| `src/sql/` | 建库与迁移脚本，**按编号顺序执行**，受控 DDL 且留 sha256 |
| `src/run/` | 计划任务入口（在院快照、防火墙等） |
| `docs/` | 本文档集 |

### 1.3 数据流向

```
HIS / 源库（只读）  ──►  作业层 src/etl  ──►  drg 库  ──►  Web 工作台
      ▲                                                      │
      └──────────── 官方结算返回清单（CSV 导入）◄──────────────┘
```

源库**只读**：作业层有只读 SQL 护栏，写入只发生在自建的 `drg` 库。

## 二、使用方案

### 2.1 部署前置

| # | 项 | 说明 |
|---|---|---|
| 1 | 运行环境 | Python 3.11；SQL Server（自建 `drg` 库） |
| 2 | 依赖 | `pip install -r src/etl/requirements.txt`、`pip install -r src/web/backend/requirements.txt` |
| 3 | **源库契约** | `src/config/source_schema.json`（表名）、`src/config/source_columns.json`（列名）——**把每个值改成本现场的真实名** |
| 4 | 连接配置 | `src/config/settings.py` 的 `PROFILES`，或用环境变量 `DRG_SBO_HOST/PORT/USER/PASSWORD` 覆盖 |
| 5 | 建库 | 按 `src/sql/` 编号顺序执行（幂等）：`$env:DRG_ALLOW_DDL=1; python src/etl/s18_create_drg_db.py --create` |
| 6 | 建号 | `python src/web/backend/seed_users.py`（**必须先注入 `DRG_INIT_PWD`**，脚本拒绝默认弱口令） |

改完 3、4 两步后，先跑 `python src/etl/s00_env_check.py` 自检（12 个关键对象在位 + 代码里没有写回物理名）。

### 2.2 日常作业

| 场景 | 作业 | 产出 |
|---|---|---|
| 结算返回导入与比对 | `s01` → `s02` | `src/out/compare/` |
| 分组回测与回归门槛 | `s03`/`s04` → `s09` → `s11` → `s20` | `src/out/adrg/` |
| 财务对账与盈亏 | `s07` → `s08` | `src/out/recon/`、`src/out/board/` |
| 在院模拟 | `s06` | `src/out/insim/` |
| 编码发现 | `s14` | `src/out/coding/` |
| 装载与新鲜度 | `s18 --load`、`s19` | drg 库、`src/out/` |

完整作业清单与参数见 **`15-代码模块说明与作业手册.md`**。

### 2.3 工作台与角色

五类视图：医师 / 财务 / 收费 / 信息科 / 医务科，权限矩阵由后端统一校验并写审计日志。
详见 **`29-多角色工作台平台方案.md`** 与 **`产品功能手册.md`**。

### 2.4 运维

- 新鲜度与告警：`s19` + 运维接口（`ops_alert`）；
- 受控 DDL：`DRG_ALLOW_DDL=1` 才执行 `src/sql/` 下脚本，逐条记录 sha256；
- 凭据密文化：`src/config/secure.py`（Windows DPAPI / Fernet），仓库只留 `.example.json` 模板；
- 回滚：先备份 `drg` 库，再回退代码版本，按 `src/sql/` 反向执行。

详见 **`25-运维监控与新鲜度告警.md`**。

### 2.5 口径与边界（对外引用数字前必读）

- **分组一致率的分母 = 可评估病例**（产出了预测的病例）。把"源表缺诊断码、产不出预测"的
  病例计入分母会把一致率平白拉低；`adrg_predictions.csv` 已带 `assessable` 列显式标记该口径。
- **盈亏三列**：`profit_formula`（支付标准 − 成本）、`profit_adjust`（调整项）、
  `profit_basis`（口径来源），恒等式 `profit_loss = profit_formula + profit_adjust`。
- **对账范围随结算返回自动推导**，不固定月份；不同区间的数字不可直接比较。
- **分组器能力边界**：见 `30-分组器业务逻辑与诊断精确度边界.md`。
